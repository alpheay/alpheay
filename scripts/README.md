# Profile artwork

The profile uses a monochrome palette, system fonts, and original vector
illustrations. Every panel has a desktop composition and a separate mobile
composition, selected by the README's `<picture>` elements at 600 px.

Rebuild all 22 SVGs from the repository root:

```sh
python3 scripts/build_art.py
```

The generator uses only Python's standard library. Its output is deterministic;
edit the generator instead of the generated files. Project titles, descriptions,
and technology labels live in `PROJECTS`. Destination links and accessible image
descriptions live in the root README.

The SVGs contain no scripts, external fonts, embedded images, or remote assets.
They have fixed black backgrounds in both GitHub themes. All essential content
is static. The existing contribution animation remains in a collapsible section
and continues to be generated by its existing workflow.

When updating the profile, render the README through GitHub's Markdown API and
inspect it with GitHub's Markdown styles in dark and light mode. Check desktop
and mobile widths, image loading, text clipping, and destination links. The
screenshots in `docs/previews/` show the top of each layout at the time of this
revamp.
